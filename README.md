# Планировщик задач

Веб-сервер для управления задачами с поддержкой повторения

## Запуск

1. Необходим .env файл:


TODO_PORT=7540
TODO_DBFILE=scheduler.db


2. поднимаем сервер: 

go run main.go


3. запускаем тесты:

 go test ./tests -v


4. URL сервера:

http://localhost:7540
